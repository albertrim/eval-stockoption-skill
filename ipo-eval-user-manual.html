ipo-eval 사용 설명서

우리 회사가 코스닥에 가면 내 스톡옵션은 얼마일까 — 실데이터로 계산하는 재미용 계산기

회사 질문 여덟 개, 스톡옵션 질문 일곱 개. 답하고 나면 상장 가능성, 예상 시가총액, 주당 가격, 내 옵션의 세후가치와 현재가치를 계산해 Threads에 바로 붙일 글로 돌려줍니다.

근거는 최근 5년 코스닥에 직접 공모로 상장한 회사 339곳과 1999년부터의 예비심사 청구 이력 2,108건입니다. 투자 판단용은 아닙니다. 입력한 회사·옵션 정보는 내 컴퓨터 밖으로 나가지 않습니다.

1무엇을 하는 스킬인가

모드가 둘입니다. 회사 모드는 회사가 상장하면 얼마짜리가 될지, 옵션 모드는 그때 내 스톡옵션이 얼마인지 계산합니다. 옵션 모드는 회사 모드 결과를 깔고 돕니다.

숫자는 전부 공개 데이터에서 나옵니다. 어떤 회사를 비교기업으로 썼는지, 이 방식이 과거 상장사에 얼마나 맞았는지도 결과에 같이 적습니다. 그래도 미래 주가를 맞히지는 못합니다. 재미로 쓰되 근거는 다 보이게 — 이게 제가 잡은 선입니다.

2준비물과 설치

준비물왜 필요한가
Claude Code스킬을 실행하는 자리. 질문·선택 화면이 Claude Code 전용이라 다른 도구에서는 돌아가지 않습니다
python3 3.10 이상숫자 계산. 표준 라이브러리만 쓰므로 추가로 설치할 패키지가 없습니다
인터넷 (선택)데이터 업데이트 확인용. 없어도 스킬에 동봉된 데이터로 돕니다
DART API 키 (선택)회사 이름만 넣으면 매출·영업손익·발행주식수를 자동으로 채웁니다. 없으면 직접 물어봅니다

Claude Code 플러그인입니다. 대화창에 두 줄을 치면 끝납니다.

/plugin marketplace add albertrim/eval-stockoption-skill
/plugin install ipo-eval

0.2.0 이하를 쓰던 분은 옛 폴더를 먼저 지우세요. 같은 이름이 두 군데 있으면 헷갈립니다. 입력한 프로필과 DART 키는 ~/.ipo-eval/에 있어 안 지워집니다.

rm -rf ~/.claude/skills/ipo-eval

DART 키 넣기 (선택, 1분)

opendart.fss.or.kr에서 무료로 발급받아 파일 하나에 저장하면 끝입니다. 넣으면 회사 모드 질문 여덟 개 중 최대 네 개가 사라집니다.

mkdir -p ~/.ipo-eval && echo "발급받은키" > ~/.ipo-eval/dart_key

안 넣어도 됩니다. 그러면 예전처럼 전부 직접 묻습니다.

3실행 방법

Claude Code 대화창에서 부릅니다. 모드를 정해 부르거나, 그냥 불러놓고 골라도 됩니다. 말로 해도 알아듣습니다.

이렇게 치면무엇이 시작되나
/ipo-eval:company회사 모드 — 4장의 질문 여덟 개. 처음이면 여기부터
/ipo-eval:option옵션 모드 — 5장의 질문 일곱 개. 저장된 회사가 없으면 회사 모드부터 하자고 합니다
/ipo-eval:company 회사이름회사 이름까지 한 번에. 질문 1번을 건너뜁니다
"우리 회사 코스닥 가면 얼마야"회사 모드
"내 스톡옵션 얼마야"옵션 모드

회사 모드는 한 번 해두면 결과가 저장됩니다. 옵션이 여러 건이면 옵션 모드를 건마다 돌리면 됩니다. 회사 숫자가 바뀌었을 때만 회사 모드를 다시 하세요.

첫 실행 때 — 업데이트 확인

세션에서 처음 부를 때 새 데이터가 있는지 확인하고 물어봅니다. 확인은 24시간에 한 번만 하고, 인터넷이 안 되면 조용히 건너뜁니다.

비교 데이터가 2026-09-05 → 2026-10-01로 새로 나왔습니다 (상장사 351곳).
업데이트할까요? (y/n)

스킬 코드가 새 버전이면 스크립트가 고치지 않고 /plugin update ipo-eval을 안내합니다. 플러그인 폴더는 복사본이라 스스로 갱신하지 못합니다. 그 명령 하나로 코드와 비교 데이터가 함께 바뀝니다.

4회사 모드 — 질문에 차례로 답하면 됩니다

한 번에 하나씩 여덟 번 묻습니다. 정해진 보기가 있는 건 고르고, 나머지는 말하듯 적으면 됩니다. 모르면 "모름"이라고 적어도 진행되고, 그 항목은 결과에 "추정"으로 표시됩니다.

회사 이름을 넣으면 DART부터 찾아봅니다

이름을 받자마자 전자공시에서 감사보고서나 사업보고서를 찾습니다. 있으면 설립연도·매출·영업손익·발행주식수를 자동으로 채우고 그 질문은 건너뜁니다. 무엇을 어디서 가져왔는지는 8번 확인표에 접수번호까지 적힙니다.

이런 경우어떻게 되나
DART 키를 안 넣었다아무 말 없이 원래대로 전부 묻습니다
DART에 그 회사가 없다같음. 비상장이어도 감사보고서를 내는 회사면 대개 있습니다
사명이 바뀌었다옛 이름으로도 찾습니다. 등록명이 다르면 확인표에 둘 다 적고 맞는지 물어봅니다
보고서에서 일부만 읽었다읽은 것만 쓰고 나머지는 물어봅니다. 지어내지 않습니다
값이 이상하다버리고 물어봅니다 — 표 단위 오독(매출 1억 미만), 당기·전년이 같은 값, 영업손익이 매출의 3배 초과
우선주가 있다상장 전에 보통주로 바뀌므로 합산한 수를 씁니다. 보통주만 쓰면 주당 가격이 두 배로 부풀려집니다

DART로 나가는 것은 회사 이름 하나뿐입니다. 매출이나 옵션 수량 같은 입력값은 보내지 않습니다.

순서질문답 예시모르면
1회사 이름예시테크필수. 전에 입력한 이름이면 "그대로 / 일부 수정 / 새로" 중 고릅니다
2주요 비즈니스 — 무엇을 누구에게 팔아서 매출이 나는지 자세히. 매출 비중이 큰 순서로, 과금 방식까지"중소 물류사 대상 창고관리 SaaS. 월 구독이 매출의 90%, 초기 구축 용역 10%. 고객 120곳"필수. 길게 써도 됩니다. 스킬이 업종 후보를 제안하면 고르기만 하면 됩니다
3설립연도2019필수. DART가 채우면 안 묻습니다
4최근 연매출과 그 전년 매출"85억, 그 전년은 60억"최근 매출은 필수. 0이어도 됩니다. DART가 채우면 안 묻습니다
5영업이익"적자 30억"흑자/적자만 알려줘도 됩니다. DART가 채우면 안 묻습니다
6상장 단계 (아래 0~5 중 선택)3 — 예비심사 청구, 2026년 7월필수
7발행주식수, 모르면 최근 투자 라운드의 밸류에이션과 주당 가격"주식수는 모름. 시리즈 B 포스트 400억, 주당 8,000원"둘 다 모르면 주당 가격은 못 내고 시총까지만 나옵니다. DART가 채우면 안 묻습니다
8확인 — 입력 전체를 표로 보여줍니다"저장하고 계산" 또는 "수정"—

2번 답은 계산에 직접 쓰이진 않고, 업종을 정하고 비교기업을 고른 이유를 설명할 때 씁니다. Threads 글에는 안 들어갑니다.

상장 단계 0~5

3단계부터는 실제 청구 이력으로 확률을 재고, 그 전은 실측이 없어 가정 계수로 추정합니다. 결과에 어느 쪽인지 적힙니다. 3단계부터는 날짜도 함께 묻습니다. 3은 예비심사 청구일, 4는 승인일, 5는 증권신고서 제출일입니다.

단계상태확률 근거
0아직 아무것도 없음추정 청구 단계 확률 × 가정 계수 (15% / 35% / 55%)
1상장 주관사(증권사) 선정
2기술평가 통과
3거래소에 예비심사 청구실측 1999년부터의 청구→승인→상장 전환율
4예비심사 승인
5공모 진행 중 (증권신고서 제출)

입력은 ~/.ipo-eval/profiles/회사이름.json에 저장됩니다. 숫자가 이상하면(매출 음수, 만료일이 부여일보다 앞 등) 어디가 왜 이상한지 알려주고 그 질문만 다시 합니다.

"예상 시총 — 계산하지 않았습니다"매출 30억원 미만이라 업종 시총 분포를 쓰는 경로인데, 회사 규모가 상장 표본과 너무 다름최근 투자 라운드 밸류에이션을 넣으면 다시 계산합니다. 없으면 이 방식으로는 숫자를 내지 않습니다
0원인데 이유를 모르겠다행사가가 너무 높거나, 상장 시점에 행사할 물량이 아직 없음메인 글에 이유 한 줄이 함께 나옵니다
비교기업이 우리와 전혀 다른 회사들이다업종을 잘못 골랐습니다. 특히 물류·풀필먼트·창고·배송은 이커머스가 아니라 제조·산업재입니다. 이커머스 셀러가 고객이어도 그렇습니다 — 파는 게 아니라 나르는 일이니까요답글의 비교기업 이름 옆에 업종이 붙어 나옵니다. 우리 사업과 다르거나 "조건을 N단계 넓혔습니다"가 나오면 업종을 바꿔 다시 돌리세요. 실제로 풀필먼트 회사를 이커머스로 넣으면 4단계까지 넓혀 화장품·콘텐츠 회사와 비교됩니다

DART가 채운 숫자가 틀렸다보고서 표를 잘못 읽었거나, 사용자가 아는 최신 수치와 회계연도가 다릅니다8번 확인표에서 "수정"을 고르면 그 항목만 다시 묻습니다. DART 값은 감사받은 마지막 회계연도 기준입니다
DART가 다른 회사를 찾았다사명이 바뀌었거나 비슷한 이름의 회사가 있습니다확인표에 등록명이 함께 나옵니다. 다르면 "수정"을 고르세요
