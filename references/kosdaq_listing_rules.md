## 0. 요건 체계 한눈에

코스닥 신규상장 형식적 심사요건은 「코스닥시장 상장규정」 제28조제1항 7개 호로 구성된다. (S1)

| 호 | 요건 |
|---|---|
| 1호 | 주식의 분산 |
| 2호 | 경영성과 및 시장평가 등 (가목 = 수익성·매출액 / 나목 = 시장평가·성장성) |
| 3호 | 감사의견 |
| 4호 | 주식의 양도제한 |
| 5호 | 액면가액 |
| 6호 | 상근감사 |
| 7호 | 사외이사 |

기술성장기업은 제30조에 따라 **2호(경영성과 및 시장평가)만** 완화된 특례요건으로 갈음한다. 나머지 1·3·4·5·6·7호는 그대로 적용된다. (S1, 규정 제30조제3항)

**2018년부터 업력·규모·자본잠식 요건은 신규상장 형식요건에서 폐지되었다.** (S1)

## 1. 일반기업 트랙 — 수익성·매출액 기준 (규정 제28조제1항제2호 **가목**)

아래 4개 안 중 **하나**만 충족하면 된다. 대괄호는 벤처기업(이노비즈 인증기업 포함) 완화 수치. (S1)

| 안 | 이익 요건 | 시가총액 요건 | 자기자본 요건 | 매출액 요건 | 출처 |
|---|---|---|---|---|---|
| ① | 법인세차감전계속사업이익 **50억원 이상** [벤처 동일 50억원] | — | — | — | S1 |
| ② | 법인세차감전계속사업이익 **20억원 이상** [벤처 **10억원**] | 기준시가총액 **90억원 이상** | — | — | S1 |
| ③ | 법인세차감전계속사업이익 **20억원 이상** [벤처 **10억원**] | — | 자기자본 **30억원 이상** [벤처 **15억원**] | — | S1 |
| ④ | 법인세차감전계속사업이익 **있을 것** (금액 하한 없음) | 기준시가총액 **200억원 이상** | — | 매출액 **100억원 이상** [벤처 **50억원**] | S1 |

**규정 원문 (제28조제1항제2호 가목, S1 인용):**
> 가. 수익성 또는 매출액 등이 다음의 어느 하나를 충족할 것
> ① 최근 사업연도의 계속사업이익 50억원 이상
> ② 최근 사업연도의 계속사업이익이 20억원 이상(벤처기업 10억원 이상)이고, 기준시가총액이 90억원 이상
> ③ 최근 사업연도의 계속사업이익이 20억원 이상(벤처기업 10억원 이상)이고, 상장예비심사 신청일 현재 자기자본이 30억원 이상(벤처기업 15억원 이상)
> ④ 최근 사업연도에 계속사업이익이 있고, 기준시가총액이 200억원 이상이면서 최근 사업연도의 매출액이 100억원 이상(벤처기업 50억원 이상)

**적용상 유의점 (S1)**

| 항목 | 내용 |
|---|---|
| 기준 재무제표 | 매출액·이익은 **최근 사업연도의 감사받은 재무제표** 기준. 종속회사 있는 법인은 영업손익·계속사업손익·당기순손익·자본금·자기자본을 **연결** 기준, 그 밖의 재무요건(매출액 등)은 **개별** 기준 |
| 지주회사·외국지주회사·종속회사 있는 외국기업 | 전부 **연결재무제표** 기준 |
| 기준시가총액 산식 | **공모가 × 상장주식수**. 공모 후에야 확정되므로 예비심사 단계에서는 공모예정가액 **하한** 기준으로 예비 판단, 최종 판단은 신규상장 심사 시 확정 공모가 기준 |
| 자기자본 기준시점 | **상장예비심사 신청일 현재** |

**벤처기업 정의 (규정 제2조제1항제38호, S1)**
- 벤처기업법 제2조의2제1항제2호 가목 요건 충족 투자를 받은 후 **1년 경과**한 기업 (지방소재벤처기업은 1년 경과 전도 포함)
- 벤처기업법 제2조의2제1항제2호 나목·다목 요건 충족 기업
- 「중소기업 기술혁신 촉진법」 제2조제3호의2에 따른 **기술혁신형 중소기업(이노비즈)**

## 3. 기술성장기업 트랙 (규정 제2조제1항제39호, 제30조)

### 3-1. 공통 — 경영성과 특례 (규정 제30조제3항)

제28조제1항제2호(경영성과 및 시장평가) 요건을 아래 **둘 중 하나**로 갈음한다. (S1)

| 안 | 요건 | 기준시점 | 출처 |

| ① | **자기자본 10억원 이상** | 상장예비심사 신청일 현재 | S1 |

> 기업 희망에 따라 2개 기관 평가를 받은 경우 그중 **높은 등급**을 적용한다. (S1)

**혁신기술기업 대상 요건 (S1)**
- 「중소기업기본법」 제2조에 따른 **중소기업**, **또는**
- 최근 2개 사업연도 매출액 증가율(개별 재무제표 기준) 평균 **20% 이상**
- 2023년 12월부터, 중소기업법상 중소기업이 아니어도 ⓐ규모요건(매출액·자산) 충족 ⓑ첨단기술분야 기업 ⓒ중견기업의 투자기간 3년 이상 ⓓ대기업 계열사 제외 ⓔ중견기업 출자비율 50% 미만 등을 갖추면 중소기업으로 보아 혁신기술기업 해당 가능

### 3-3. 사업모델기업 — 상장주선인 추천 (규정 제30조제2항)

| 항목 | 내용 | 출처 |

## 프로그램이 쓰는 판정 기준

### 입력과 그 한계

프로그램이 받는 입력은 **`매출액(원)`, `영업이익(원)`, `자기자본(원, 없을 수 있음)`, `업종`** 뿐이다. 규정과의 간극을 먼저 명시한다.

| 규정이 요구하는 값 | 입력에 있는 값 | 처리 |
|---|---|---|
| **법인세비용차감전계속사업이익** | `영업이익` | **근사치로만 사용.** 영업외손익(이자·외환·평가손익 등)이 반영되지 않아 부호까지 뒤집힐 수 있다. 임계값 ±30% 구간은 `확인필요`로 반환하고 단정하지 않는다 |
| **기준시가총액** (= 공모가 × 상장주식수) | 없음 | **공모 전에는 산출 불가.** 시총 의존 요건은 판정하지 않고 `조건부` 목록으로만 반환한다 |
| 최근 2개 사업연도 매출액증가율 | 없음 (단년도 매출액만) | 증가율 요건(§2③)은 `추가입력필요` |
| 벤처기업/이노비즈 확인 여부 | 없음 | **업종으로 추정 불가.** 일반기업 기준(엄격한 쪽)을 기본 적용하고, 벤처 기준 적용 시의 결과를 함께 병기 |
| 자기자본 | 있을 수도, 없을 수도 | `None`이면 자기자본 의존 요건 전부를 `조건부`로 |

### 의사코드

```python
# 금액 단위: 원
億 = 100_000_000

def 판정(매출액, 영업이익, 자기자본, 업종):
    확정충족 = []      # 입력만으로 충족이 확정된 요건
    조건부   = []      # 시총/증가율 등 미지값만 채우면 충족되는 요건
    확인필요 = []      # 근사치가 임계값 부근이라 단정 불가

    PBT = 영업이익                       # 법인세비용차감전계속사업이익의 근사치
    자본미상 = (자기자본 is None)

    def 근사(값, 기준):
        """근사치 판정. 0=미달, 1=충족, None=경계라 판정불가"""
        if 값 >= 기준 * 1.3: return 1
        if 값 <  기준 * 0.7: return 0
        return None                       # ±30% 밴드 → 확인필요

    # ── 트랙 A. 일반기업 수익성·매출액 기준 (제28조1항2호 가목) ──────────
    # A①  이익 50억 단독  → 시총·자기자본 불필요, 입력만으로 판정 가능
    r = 근사(PBT, 50*億)
    if r == 1:    확정충족.append("A①  세전이익 50억 이상 (단독 충족)")
    elif r is None: 확인필요.append("A①  세전이익 50억 경계 — 영업외손익 확인 필요")

    # A③  이익 20억[벤처10억] + 자기자본 30억[벤처15억]  → 시총 불필요
    for 라벨, 이익선, 자본선 in [("일반", 20*億, 30*億), ("벤처", 10*億, 15*億)]:
        if 자본미상:
            if PBT >= 이익선:
                조건부.append(f"A③({라벨}) 세전이익 요건 충족 — 자기자본 {자본선//億}억 이상이면 충족")
        elif PBT >= 이익선 and 자기자본 >= 자본선:
            확정충족.append(f"A③({라벨}) 세전이익 {이익선//億}억 + 자기자본 {자본선//億}억")

    # A②  이익 20억[벤처10억] + 기준시총 90억  → 시총 필요
    for 라벨, 이익선 in [("일반", 20*億), ("벤처", 10*億)]:
        if PBT >= 이익선:
            조건부.append(f"A②({라벨}) 세전이익 충족 — 기준시총 90억 이상이면 충족")

    # A④  이익 有 + 기준시총 200억 + 매출 100억[벤처50억]  → 시총 필요
    for 라벨, 매출선 in [("일반", 100*億), ("벤처", 50*億)]:
        if PBT > 0 and 매출액 >= 매출선:
            조건부.append(f"A④({라벨}) 이익·매출 충족 — 기준시총 200억 이상이면 충족")

    # ── 트랙 B. 시장평가·성장성 = 이익미실현 (제28조1항2호 나목) ──────────
    # B⑤  자기자본 250억 단독  → 시총 불필요, 이익 무관
    if 자본미상:
        조건부.append("B⑤  자기자본 250억 이상이면 단독 충족 (이익 무관)")
    elif 자기자본 >= 250*億:
        확정충족.append("B⑤  자기자본 250억 이상 (단독 충족, 이익 무관)")

    # B①②③④는 전부 기준시총 의존 → 확정 불가, 조건부로만
    조건부.append("B①  기준시총 1,000억 이상이면 무조건 충족")
    if not 자본미상:
        조건부.append("B②  기준시총 500억 이상 & 공모후 시총/자기자본 200% 이상이면 충족")
    if 매출액 >= 30*億:
        조건부.append("B③  매출 30억 충족 — 기준시총 500억 & 2년평균 매출증가율 20% 이상이면 충족 [증가율 추가입력필요]")
    for 라벨, 매출선 in [("일반", 100*億), ("벤처", 50*億)]:
        if 매출액 >= 매출선:
            조건부.append(f"B④({라벨}) 매출 충족 — 기준시총 300억 이상이면 충족")

    # ── 트랙 C. 기술성장기업 (제30조) — 재무 문턱 최저 ──────────────────
    # 경영성과 특례: 자기자본 10억 OR 기준시총 90억 중 택일
    C_재무 = None
    if 자본미상:
        C_재무 = "조건부"       # 자기자본 10억 또는 기준시총 90억 중 하나만 넘으면 됨
    elif 자기자본 >= 10*億:
        C_재무 = "충족"
    else:
        C_재무 = "조건부"       # 자기자본 미달이어도 기준시총 90억이면 충족

    # 대상 요건: 중소기업 or 최근 2사업연도 매출증가율 평균 20% 이상
    #   → 중소기업 여부·증가율 모두 입력에 없음 → 판정 불가
    # 기술평가/추천: 전문평가 A&BBB 또는 상장주선인 추천 → 재무입력만으로 판정 불가
    C_주의 = ("재무 문턱은 충족 가능하나, 전문평가기관 A&BBB 등급(혁신기술기업) "
              "또는 상장주선인 사업모델 추천(사업모델기업)이 별도로 필요 — 재무입력만으로 판정 불가")

    # ── 업종의 역할 (형식요건 판정에는 직접 사용하지 않음) ─────────────
    # 업종은 아래 3가지 '힌트'로만 쓴다. 요건 통과/탈락 판정에 쓰지 않는다.
    힌트 = []
    if 업종 in {"바이오", "제약", "의료기기", "AI", "인공지능", "우주",
                "신재생에너지", "ESS", "반도체", "방산"}:
        힌트.append("기술성장기업 트랙 우선 검토 대상 업종 — "
                    "'25.12.31 시행 AI·에너지·우주 맞춤형 질적심사기준 적용 가능")
    if 업종 in {"소재", "부품", "장비", "소부장"}:
        힌트.append("소부장 전문기업 인증 시 전문평가기관 1곳 A등급만으로 신청 가능")
    if 업종 in {"국가전략기술", "국가첨단전략기술", "딥테크"}:
        힌트.append("딥테크(초격차) 특례: 기준시총 1,000억 + 최근5년 벤처금융 100억 충족 시 "
                    "전문평가기관 1곳 A등급만으로 신청 가능")
    힌트.append("중소기업기본법상 매출 규모기준은 업종별로 다름 — 상한 수치 확인 실패(§7-1)")

    return {
        "확정충족": 확정충족,          # 비어 있지 않으면 → 해당 트랙 진입 가능
        "조건부":   조건부,            # 시총/증가율 확정 후 재판정
        "확인필요": 확인필요,
        "기술성장_재무": C_재무,
        "기술성장_주의": C_주의,
        "업종힌트": 힌트,
        "권고트랙": 권고(확정충족, 조건부, PBT, 자기자본),
    }


def 권고(확정충족, 조건부, PBT, 자기자본):
    """단일 권고 트랙 산출"""
    if any(s.startswith("A") for s in 확정충족):
        return "일반기업 — 수익성·매출액 기준 (가장 확실)"
    if any(s.startswith("B⑤") for s in 확정충족):
        return "일반기업 — 시장평가·성장성 기준 ⑤ (자기자본 250억 단독)"
    if PBT is not None and PBT > 0:
        return "일반기업 — 수익성·매출액 기준 (조건부). 공모가 확정 후 기준시총으로 재판정"
    return ("이익미실현(시장평가·성장성) 또는 기술성장기업 트랙. "
            "기술성장기업은 재무 문턱(자기자본 10억 or 기준시총 90억)이 가장 낮으나 "
            "전문평가 등급 또는 상장주선인 추천이 별도 필요")
```

### 자기자본·시가총액을 모를 때의 처리 규칙

| 미상 값 | 판정 가능한 요건 | 판정 불가 (조건부로 반환) |
|---|---|---|
| **시가총액만 미상** (항상 그러함, 공모 전) | A① (세전이익 50억), A③ (이익+자기자본), B⑤ (자기자본 250억), 기술성장 자기자본 10억 | A②, A④, B①, B②, B③, B④, 기술성장 시총 90억 |
| **자기자본도 미상** | A① (세전이익 50억) **한 가지뿐** | 나머지 전부 |
| **둘 다 미상** | A①만. 그 외에는 **`판정불가`를 반환하고 자기자본 입력을 요구**한다 | — |

**설계 원칙**
1. **시총 요건은 절대 단정하지 않는다.** 기준시가총액은 공모가 × 상장주식수로 공모 후 확정되며, 예비심사 단계에서도 거래소는 공모예정가액 **하한**으로 예비 판단할 뿐이다. (S1)
2. **`영업이익`으로 `세전계속사업이익`을 대체할 때는 경계 밴드(±30%)를 `확인필요`로 빼낸다.** 두 값의 차이는 영업외손익이며, 이자비용이 큰 기업은 영업이익 흑자·세전 적자가 흔하다.
3. **업종은 트랙 힌트로만 쓰고 통과/탈락 판정에 넣지 않는다.** 코스닥 형식적 진입요건에 업종 기준은 없다. 업종은 ①기술성장 트랙 적합성, ②전문평가 1곳 완화 대상(소부장·딥테크), ③'25.12.31 신설 맞춤형 질적심사기준(AI·에너지·우주) 적용 여부에만 영향을 준다.
4. **벤처 여부를 모르면 일반기업 기준(엄격)으로 판정하고 벤처 기준 결과를 병기한다.** 벤처확인·이노비즈 인증은 별도 확인서로만 입증되며 업종에서 추론할 수 없다.
5. **한 개 안만 충족해도 `확정충족`이다.** 제28조제1항제2호는 가목·나목 각각 택일 구조이므로 모든 안을 다 볼 필요가 없다.
